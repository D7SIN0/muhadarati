# مُحاضرتي — Smart Lecture

موقع عربي (RTL) يعمل على الجوال والتابلت والبروجكتر. Next.js 14 + Tailwind.

## تشغيل محلي (دقيقتين)
```bash
npm install
cp .env.example .env.local     # عدّل DOCTOR_KEY و SESSION_SECRET على الأقل
npm run dev                    # http://localhost:3000
```
بدون أي مفتاح ذكاء اصطناعي يشتغل **المساعد المحلي** (يجيب من نصوص المحاضرات والملفات مع ذكر المصدر). الاختبارات تتولد محلياً أيضاً.

## نشر على Vercel (مجاني)
1. ارفع المجلد على GitHub، ثم Vercel ← Add New Project ← اختر المستودع.
2. من Settings ← Environment Variables أضف:
   - `SESSION_SECRET` نص عشوائي طويل
   - `DOCTOR_KEY` كلمة سر الدكتور (مهم)
   - `SMART_SCREEN_KEY` مفتاح الرفع التلقائي من الشاشة الذكية
   - `GEMINI_API_KEY` و/أو `XAI_API_KEY` (Grok) — اختياري. إذا وُجد الاثنان يجرّب Gemini ثم Grok تلقائياً (`AI_ORDER=gemini,grok`).
   - `BLACKBOARD_URL` رابط Blackboard الافتراضي (والدكتور يقدر يعدّله من لوحته)
3. **تخزين دائم (مهم للعرض الحي):** بدون إعداد، البيانات على Vercel مؤقتة وقد تُمسح. أنشئ قاعدة Upstash Redis مجانية وأضف
   `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN`.
4. Deploy ← خذ الرابط ← الباركود يتولد تلقائياً في الصفحة الأولى.

## الصفحات
- `/` الصفحة الأولى (فكرة، مميزات، زر الشرح التوضيحي، الباركود ونسخ الرابط)
- `/demo` شرح توضيحي خطوة بخطوة ببيانات تجريبية جاهزة (بدون حساب وبدون كتابة اسم): الدخول، الرئيسية، المحاضرات، المساعد (محادثة جاهزة)، الاختبار، الدكتور، العرض، الخصوصية
- `/enter` الدخول بالاسم الأول → رمز رجوع 6 أرقام (مُشفّر، يُعرض مرة وحدة) · `/recover` استرجاع
- `/app` لوحة الطالب · المحاضرات · الملخصات · المساعد · اختبر نفسك · الجدول · المحفوظات · حسابي (باركود، رمز جديد، حذف البيانات)
- `/doctor` الدكتور: رفع PDF/PowerPoint/نص، رابط Blackboard لكل مادة، محاكاة الشاشة الذكية، حذف، **اعرض** (وضع البروجكتر، أسهم الكيبورد)
- `/privacy` الخصوصية

## الرفع التلقائي من الشاشة الذكية
```bash
curl -X POST https://YOUR-SITE/api/ingest \
  -H "x-api-key: SMART_SCREEN_KEY" -H "Content-Type: application/json" \
  -d '{"course":"ent","title":"عنوان المحاضرة","slides":["عنوان الشريحة\n- نقطة 1\n- نقطة 2"]}'
```
(`course`: `ent` أو `com`. أو أرسل `text` بدل `slides`.) صيغة ما تخرجه الشاشة فعلياً تُحدَّد لاحقاً.
